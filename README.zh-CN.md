<h1 align="center">AgentShade</h1>

<p align="center"><strong>屏幕暂暗，工作不停。</strong></p>

<p align="center"><a href="README.md">English</a> · 简体中文</p>

AgentShade 是一款轻量、原生的 macOS 菜单栏工具：遮住屏幕，但不停止背后的工作。按一个全局快捷键，即可显示纯黑、自选图片或动态 GIF、毛玻璃遮罩；在支持的 Mac 笔记本上，还可选用随合盖逐渐加深的角度毛玻璃。

AgentShade 只创建全屏遮罩窗口，不修改硬件亮度，不暂停终端、构建或下载，也不会主动让 Mac 休眠。遮罩显示期间，后台进程通常会继续运行。

## 快速使用

1. 启动 AgentShade，点击菜单栏图标，通过“设置…”进入统一设置页面。
2. 按 `⌃⌥⌘D` 遮住选定屏幕；默认按任意普通按键即可恢复。
3. 如需自动遮罩，进入“合盖渐变”，在检测到可用角度传感器后启用。快捷键与合盖两种方式独立配置。

## 主要亮点

- 使用默认快捷键 `Control + Option + Command + D` 遮住所有已连接显示器。
- 可选纯黑、自选图片 / GIF 或固定毛玻璃底图。
- 快捷键遮罩与合盖遮罩可分别选择全部显示器或仅内置屏幕。
- 显示器接入、断开或排列变化时自动调整遮罩。
- 可自定义全局快捷键，也可设为必须再次按该快捷键才退出。
- 在具有可读取角度传感器的硬件上启用平滑合盖渐变。
- 可选为增强合盖毛玻璃抓取一帧仅存内存的桌面图像。
- 未授权、权限不可用或取图失败时，始终保留无需权限的内置底图。
- 完整界面可在简体中文与英文之间即时切换。
- 通过 macOS 标准登录项服务设置登录时启动。

## 三组清晰设置

### 1. 快捷键遮罩

“快捷键遮罩”管理手动触发的屏幕覆盖。

- **场景：**纯黑、图片 / GIF 或毛玻璃；默认纯黑。
- **显示范围：**默认全部显示器，也可只遮内置屏幕。
- **全局快捷键：**默认 `⌃⌥⌘D`；自定义组合必须包含 Command 或 Control，并搭配受支持按键。
- **退出方式：**默认按任意键恢复；该按键会被拦截，不再发送给之前聚焦的应用。
- **仅快捷键退出：**可选；开启后忽略其他按键，只用已设置的快捷键恢复。
- **毛玻璃强度：**默认 50%，调节固定蓝色材质的深浅，不是让桌面透出一半。
- **自选媒体：**支持 GIF、PNG、JPEG、HEIC 与 WebP，支持动态 GIF 播放。

鼠标点击不会退出遮罩。恢复前，遮罩会吸收指针操作。

手动“毛玻璃”刻意使用 AgentShade 自带的固定底图，不采集、不透出、也不模糊真实桌面，因此无需“屏幕录制”权限。

### 2. 合盖渐变

“合盖渐变”为可选功能，默认关闭。只有 AgentShade 在运行时检测到可读取的开合角度传感器后，才能启用。

- **起效角度：**默认 80°，可在 41°–95° 调整。
- **恢复角度：**始终比起效角度高 5°，避免反复触发。
- **触发条件：**角度需低于起效角度并保持约 100 毫秒。
- **渐变曲线：**以所设起效角度到 40° 为完整行程，合拢 30% 时达到 65% 强度；40° 时达到最深。
- **角度动画：**默认开启；关闭后触发即使用设定的完整强度。
- **模糊半径：**默认 20，桌面快照模糊可用时可在 0–60 调整；不影响无需权限的内置底图。
- **显示范围：**默认全部显示器，与快捷键遮罩独立设置。
- **增强毛玻璃：**默认开启；仅在屏幕录制权限实际可用时读取桌面快照。

用户手动解除自动遮罩后，本轮低角度期间不会再次触发。先将屏幕抬到恢复角度，再次压低才会重新触发。

### 3. 通用

- 在英文与简体中文之间即时切换。
- 开启或关闭登录时启动。
- 查看屏幕录制权限状态，并通过当前可见的权限按钮请求授权或打开相应的系统设置页面。

首次启动时，系统首选语言第一项为中文则选择简体中文，其他语言选择英文。此后，已保存的应用内选择优先，不随系统语言变化而自动覆盖。

设置窗口采用固定尺寸。失去焦点或被部分遮住时不会关闭；持续完全遮挡才会关闭并恢复合盖自动化。操作录屏提示或系统设置期间属于例外：返回时会保留设置，确认窗口重新可见后才恢复普通遮挡判断。

## 系统要求与兼容性

- macOS 13 或更高版本。
- 从源码构建需要兼容 Swift 5.9 的工具链 / Xcode Command Line Tools。
- 手动遮罩不需要开合角度传感器。
- 自动合盖遮罩需要运行时发现的、可读取的 Apple HID 方向传感器。

当前实现通过 HID 读取开合角度，尚未完成覆盖所有 MacBook 型号的兼容性验证，因此以当前 Mac 的实际检测结果为准。传感器不可用时，AgentShade 会禁用合盖自动功能，手动遮罩仍可使用。

AgentShade 仅支持 macOS，没有 Windows 版本。Swift Package 未强制指定 CPU 架构，打包脚本会跟随当前 Swift 工具链和主机目标构建，并未声明生成 Universal 通用二进制。

## 从源码构建与安装

项目现有的 GitHub Release 暂未附带预编译 App。请从源码构建当前版本：

```bash
git clone https://github.com/simp1eby/agentshade.git
cd agentshade
./scripts/package-app.sh
open outputs
```

脚本会生成 `outputs/AgentShade.app`。如果本机已安装名为 `AgentShade Local Signing` 的证书，会自动复用；否则使用 ad-hoc 临时签名。也可以通过 `AGENTSHADE_SIGNING_IDENTITY` 指定已有签名身份。新包先在临时目录完成签名与校验，再替换旧 App；拒绝签名或校验失败时会保留旧包。macOS 可能要求你在钥匙串提示中确认使用签名私钥。重新构建 App 包前，请先退出正在运行的 AgentShade。

最后一条命令会打开输出文件夹：请将 App 拖入 `/Applications`（应用程序），再从那里启动。授权或启用登录时启动前，请保持安装位置稳定。本机证书不等于 Apple Developer ID 签名或苹果公证。仓库不包含证书和私钥，请勿将它们提交到 Git。

如果 macOS 要求批准登录项，请前往**系统设置 → 通用 → 登录项与扩展**允许 AgentShade。

未来若发布预编译包，会显示在 [GitHub Releases 页面](https://github.com/simp1eby/agentshade/releases)。在此之前，以上源码构建是本文档说明的安装方式。

## 屏幕录制：可选且用途明确

纯黑、自选媒体、手动毛玻璃和合盖模式的内置底图都不需要屏幕录制权限。只有用户在设置中主动点击授权按钮时，AgentShade 才会请求权限。

权限可用时，增强**自动合盖遮罩**会为每个所选显示器抓取一帧完整图像，排除 AgentShade 自己的窗口，并在本机应用模糊与统一蓝色材质。图像只保存在内存中，不落盘、不上传，不包含音频或鼠标指针，也不是持续视频录制；解除遮罩后会释放所抓取的像素。

AgentShade 将 macOS 权限开关与实际取图成功视为两件事。如果取图失败或不完整，会改用内置渐变底图。

**毛玻璃能用，不代表录屏权限已授权。**“内置毛玻璃可用”表示无需权限的底图效果可用；“录屏已授权”表示当前 App 取得了权限，而下方说明会另外显示是否已验证取图、或取图失败。喜欢内置效果就不必授权。“合盖渐变”与“通用”页都会直接展示这些状态，不需要把鼠标悬停在按钮上查看。

授权后，请退出并重新打开同一个 AgentShade App。ad-hoc 重新构建可能改变应用的隐私身份，因此即使系统设置仍显示 AgentShade，旧授权也可能不再匹配。请保持 App 路径稳定、重启该准确 App，并用“合盖渐变”或“通用”页的屏幕录制按钮重新打开系统设置，确认当前 App 条目。

AgentShade 的全局快捷键和日常运行不请求“辅助功能”权限。

## 遮罩能做什么、不能做什么

- **后台工作：**AgentShade 只增加窗口，因此终端、本地 Agent、构建、下载与其他进程通常会继续运行。
- **前台焦点：**显示遮罩时，AgentShade 会成为活跃应用，以接收并拦截恢复按键。依赖前台键盘或指针输入的 GUI 自动化与 Agent，需要单独验证兼容性。
- **仅内置屏行为：**使用普通按键退出时，如果把焦点移到未遮挡外接屏上的应用，遮罩会自动解除，避免成为失焦后无法控制的陷阱。手动开启“仅快捷键退出”后则会按设计保持遮罩。
- **睡眠：**AgentShade 不设置防休眠断言，也不修改 macOS 合盖策略。完全合盖仍可能让 Mac 休眠；重新打开后发现进程仍在，不等于它在合盖期间持续执行。
- **唤醒：**显示器睡眠期间，AgentShade 会暂停传感器读取与渲染，同时保留当前遮罩；唤醒后按需恢复检测并刷新仍在显示的遮罩，但不能保证控制系统唤醒的第一帧。
- **隐私强度：**纯黑是完全不透明的选择。增强毛玻璃会刻意保留部分视觉结构，尤其在起效角度附近；它不是锁屏，系统锁屏仍由 macOS 负责。

应用会作为菜单栏 Agent 常驻以响应全局快捷键，但这不代表能够阻止系统睡眠，也不保证前台自动化不中断。

## 本地数据与隐私

AgentShade 会把选中的自定义背景保存到当前用户的 Application Support 目录，并在本地保存场景、快捷键、语言、显示范围和合盖设置等偏好。开合角度读数只停留在内存中。

应用源码中没有账号系统、分析 SDK、遥测管线或网络服务。增强合盖毛玻璃使用的屏幕图像仅在本机短暂存在。

## 开发检查

推荐的专项检查：

```bash
./scripts/run-checks.sh --default-blur
./scripts/run-checks.sh --lid-curve
./scripts/run-checks.sh --language-permissions
./scripts/run-checks.sh --permission-presentation
./scripts/run-checks.sh --permission-occlusion
./scripts/run-checks.sh --simple-lid
```

创建 AppKit 窗口、操作真实遮罩或读取硬件的检查，需要在已登录的 macOS 图形会话中运行。可选的集成与传感器检查为：

```bash
./scripts/run-checks.sh --integration --sensor
```

集成与传感器选项会短暂测试真实遮罩和 HID 读数；没有可读取角度传感器的硬件应省略 `--sensor`。语言与权限检查使用测试权限提供器，不会授予屏幕录制权限，也不会采集桌面。
